Online Pizza Delivery Web Application
Overview
The Online Pizza Delivery Web Application is designed to provide users with a seamless experience for ordering pizza online. The application allows users to browse through a variety of pizzas, customize their orders, simulate payment, and receive real-time delivery status updates.
```
$ git https://github.com/Swathi-Reddy1408/PizzaTime.git
$ cd OnlinePizzaOrderingSystemAngular
$ npm install
$ ng serve 
```
